# Chatil Store

A responsive Arabic RTL storefront prototype for Chatil Accessories, tailored for customers in Egypt.

## Current scope
- Responsive storefront and product cards
- EGP pricing
- Interactive shopping cart (client-side demo)
- Brand/story and newsletter sections
- No payment credentials, secrets, or third-party paid services

## Important
Checkout and newsletter submission are UI demonstrations only. Orders, payments, shipping, product management, and newsletter persistence are not connected yet. Connect these to the Supabase project only after defining the order flow and access policies.
